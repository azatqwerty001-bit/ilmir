# Тёплый угол — учебный заказ

Представим, что локальная кофейня заказала сайт из трёх страниц. Цель: познакомить посетителей с заведением, показать меню с ценами, часы работы и адрес. Название, история, адрес и цены вымышлены. Перед реальной публикацией заказчик должен подтвердить эти данные.

## Требования заказчика

- Спокойное оформление в кремовых и зелёных тонах, крупный фотоэкран и фотографии интерьера.
- Первый экран с понятным предложением и переходом к меню.
- Фотоменю из восьми позиций с фильтрами «Всё меню», «Кофе», «Сезонное», «Выпечка и завтраки».
- Разделы о кофейне, адрес и расписание.
- Удобная версия для телефона с раскрывающейся навигацией.
- Работа без регистрации, ключей, внешних библиотек и установки зависимостей.

Сайт информационный: онлайн-заказы, оплата и бронирование в этот заказ не входят. Оптимизированные фотографии Unsplash в формате WebP находятся в `assets/`. Во время просмотра внешние изображения и шрифты не загружаются. При скачивании сайта сохраните также папку `assets/`. Описание дизайна и статус изучения конкурентов — в `DESIGN.md`.

## Запуск

Откройте `index.html` в браузере на компьютере. Для облачной среды из `/workspace/ilmir`:

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

Сервер разработки останавливается через Ctrl+C. Публикация сайта в интернете — отдельный шаг.

## Как устроен сайт

- `index.html` — главная страница: знакомство с кофейней и три популярных позиции.
- `menu.html` — полное меню с ценами и фильтрами.
- `contacts.html` — адрес, расписание и ответы на вопросы гостей.
- `style.css` — цвета, шрифты, сетка и мобильная версия.
- `script.js` — фильтры меню и раскрытие навигации на телефоне.

## Проверка перед сдачей

1. Ссылки «Главная», «Меню» и «Контакты» открывают соответствующие страницы; «О нас» открывает раздел на главной. Текущая страница выделена.
2. Категория «Кофе» показывает три напитка, «Выпечка и завтраки» — три блюда, «Сезонное» — две позиции, «Всё меню» — восемь позиций.
3. На телефоне кнопка меню раскрывает ссылки. Выбор ссылки или Escape закрывает меню.
4. На ширине 390 пикселей нет горизонтальной прокрутки.
5. Без JavaScript все позиции и ссылки остаются доступны.

## Первое упражнение

Найдите капучино в `menu.html` и измените цену. На главной есть его краткая карточка — обновите цену и в `index.html`, чтобы она совпадала. Обновите страницу и проверьте результат. Затем попробуйте изменить цвет `--green` в начале `style.css`.

## Дополнительные возможности

В карточках раскрывается состав и аллергены, есть пометки о декафе и альтернативном молоке. В контактах — галерея фотографий-примеров и демонстрационные кнопки маршрута, телефона и соцсети. Реальные контакты пользователь не предоставлял и попросил оставить вымышленными: кнопки объясняют, какие данные нужны, вместо звонков и переходов на чужие страницы. Без JavaScript контакты описаны текстом, а состав раскрывается штатными средствами браузера.

## Публичная версия

Сайт подготовлен для GitHub Pages: источник — ветка `main`, корень репозитория. Обновление файлов в `main` запускает публикацию GitHub Pages. Публикация облачной среды и размещение сайта — разные операции. Для публикации нужны `index.html`, `menu.html`, `contacts.html`, `style.css`, `script.js` и используемые файлы из `assets/`. Исходные JPG и старые SVG-карточки не требуются.
