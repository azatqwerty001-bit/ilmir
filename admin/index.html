Вход

Используйте пароль, который установили при запуске учебного сервера.

Здесь нужен сервер

GitHub Pages показывает готовые страницы. Для работы админки запустите учебный сервер на своём компьютере:

python3 admin_server.py --init
python3 admin_server.py

Затем откройте адрес, который напечатает сервер. Инструкция находится в ADMIN.md.

Посмотреть сайт ↗

Сохранение обновляет учебный сервер для всех его посетителей. Чтобы изменить публичный сайт GitHub Pages, скачайте ZIP и загрузите его содержимое в репозиторий. Несохранённые изменения в ZIP не попадают.
